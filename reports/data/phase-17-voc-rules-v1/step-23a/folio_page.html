Step 23a: read the folio number at the top of 240 scans

Each item is a crop of the top of one scan (Nationaal Archief image server; internet needed). Type the folio number written on the front sheet in the top right corner. On a two-page scan (an opening) that is the right-hand page. Zoom in on the crop with the mouse wheel or a pinch and drag to pan (sharper detail loads as you zoom); whole page shows the full scan if the number sits lower. About 30 to 40 minutes in all.

Number
The folio number as written (e.g. 288, 1036). Press Enter to save and go on. Digits only, as written; add a letter if one is written (288a).
No number (n)
The sheet is clearly there but carries no number (a cover, a blank sheet, a page with a number only on the left).
Unreadable (u)
A number seems to be there but you cannot read it, or the crop does not show the page top.
Left page number
Optional. On an opening whose left page is also numbered, the number at the top of the left page.
Number on a sheet beneath
Optional. A smaller sheet lies on a larger one and the larger sheet's number shows: type that number here, and the number of the front sheet above.
Keys
Enter save and next; n no number; u unreadable; ← and → previous and next item.
